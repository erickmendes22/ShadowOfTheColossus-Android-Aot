# Créditos / Credits — Shadow of the Colossus Android AOT

Este projeto reutiliza e adapta trabalho de terceiros. Os respectivos direitos autorais, licenças e contribuições permanecem com seus autores. Os créditos históricos identificam a origem dos componentes e não devem ser interpretados como uma lista de motores de CPU efetivamente executados no APK 0.2.0.

- **[AjncSystem / ShadowOfTheColossus-PC](https://github.com/AjncSystem/ShadowOfTheColossus-PC)** e colaboradores: port nativo original para PC, suporte ao jogo, patches e integrações de renderização, correções e desempenho.
- **[bloodborne_pc](https://github.com/Supermedo/bloodborne_pc)**: **Supermedo, deadinside28 e forks**; base do carregador, runtime e estrutura nativa usada pelo projeto de PC.
- **[shadPS4](https://github.com/shadps4-emu/shadPS4)** e **[Pink-shadPS4](https://github.com/luizgustavs/Pink-shadPS4)** (incluindo **luizgustavs**): núcleo Vulkan e compatibilidade gráfica PS4.
- **Colaboradores do port PC**, citados por AjncSystem: **Oussama268, Lucas-blip-png, Gabriell-os, jownatan, xeodeo, nakaionyt/y7ngboy, tabnul, EdouardSence, Einar, KingJhoss, nosekefik e raulbezerro-dev**, entre outros. Patch de 60 FPS: **illusion**. Consulte também os créditos e o histórico no projeto original.
- **[ducvd89/Bloodborne-Android](https://github.com/ducvd89/Bloodborne-Android)** e **[Bloodborne Android rebuild tooling](https://github.com/ducvd89/Bloodborne-android-rebuild-tool)**: referências e ferramentas para execução Android Bionic e compilação ARM64 AOT, adaptadas neste port.
- **[cobrabm12/fexdroid](https://github.com/cobrabm12/fexdroid)**: origem histórica de componentes de interface, controles e bridges Android. **O runtime FEX não é distribuído nem executa o código do jogo neste APK**, que utiliza AOT ARM64 nativo; o nome do pacote Java e os avisos de licença preservam sua procedência.
- **[Mesa / Turnip](https://gitlab.freedesktop.org/mesa/mesa)** e contribuidores de **Droid-Deck/DD/GameHub**: tecnologia do driver Vulkan integrado. Licenças próprias dos drivers se aplicam.
- **erickmendes22 / [Daedalus Emulator](https://www.youtube.com/@daedalusemulator)**: adaptação Android, launcher, manutenção, integração, testes em dispositivos e empacotamento.
